# Experiments

This directory contains the documentation and results of each
reinforcement learning experiment.

Each experiment should have its own numbered directory:

    experiments/
    ├── 001/
    ├── 002/
    ├── 003/
    └── ...

An experiment may contain:

- README.md — experiment description, hypothesis and conclusions
- config.json — parameters used during training
- results.json — training results and metrics
